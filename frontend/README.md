# Connect Backoffice – Frontend Application

Independent React + TypeScript + Vite + Tailwind CSS operational platform for Connect App.

## Environment Variables
Copy `.env.example` to `.env`:
- `VITE_API_URL=/api` (Proxied to backend `http://localhost:8007` in Vite dev mode)

## Scripts
- `npm run dev` — Start Vite dev server on `http://localhost:5175`
- `npm run build` — Compile TypeScript and build production bundle to `dist/`
- `npm run preview` — Preview production build
